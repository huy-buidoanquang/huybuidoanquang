This site started with a simple question: how do you build a personal portfolio that feels atmospheric and authored without burying the writing behind heavy scripts?

## From WebGL to layered stillness

Early prototypes explored a full 3D canvas tied to scroll. While expressive, it asked every visitor to download an entire rendering engine just to read an essay or open a project link. Replacing geometry with two coordinated painted backdrops, lightweight CSS transitions, and a tiny smoothstep blend kept the sense of travel while cutting away the overhead.

## Built to be written in

Everything lives as plain Markdown and MDX inside GitHub, validated at build time by strict Astro content schemas and deployed as static HTML on Cloudflare Pages. No database, no CMS login — just text, photographs, and a fast path from a rough field note to a live page.
