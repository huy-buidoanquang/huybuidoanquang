# Art direction for each story

Each new destination gets its own brief before its page is styled. Record:

1. **Place evidence:** official tourism or heritage sources for architecture, landscape, climate, and recurring visual motifs. Keep a link and access date.
2. **Photo measurements:** actual image count, aspect ratios, dimensions, file sizes, and a sampled color palette. Choose a lead image, quiet images, and detail images before choosing layout.
3. **Current interest:** check a dated trend source for the place and record exactly what it measures. Search volume, social engagement, and tourist arrivals are different signals; never substitute one for another.
4. **Design decision:** typography, type scale, pace of movement, photo order, captions, and layout. Explain how each follows from the place and the owner's own photographs.
5. **Reading check:** body text, captions, keyboard focus, reduced motion, phone layout, and lazy image loading.

The preview uses sample images. Replace them with the owner's photographs and repeat the brief before public launch.
